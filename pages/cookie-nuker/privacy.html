Data Collection

Cookie Nuker does not collect any data. Specifically, the extension does not collect:

  • ✗Personal identifiable information (name, email, address, phone number)
  • ✗Browsing history or browsing activity logs
  • ✗Search queries
  • ✗Form data or user input
  • ✗Cookies or storage contents
  • ✗IP addresses or location data
  • ✗Device information
  • ✗Usage statistics or analytics
  • ✗Any user content whatsoever

The extension has no analytics SDK, no tracking scripts, no telemetry, and no backend servers.

Permissions Requested

Cookie Nuker requests the minimum permissions necessary to function:

activeTab: Grants temporary access to the currently active tab only when the user clicks the extension icon. This permission is used to read the active tab's URL for display purposes and to inject cleanup scripts into the page context. The permission expires when the popup closes and never runs in the background or on page load.

browsingData: Allows the extension to clear cookies, localStorage, IndexedDB, cache storage, service workers, and other site data using Chrome's native browsingData API. This permission is activated only when the user clicks the NUKE EVERYTHING button. No host permissions are needed for this API.

scripting: Allows the extension to execute JavaScript functions in the active tab's page context. This is necessary because certain storage types (localStorage, sessionStorage, IndexedDB, Cache Storage, Service Workers, Shared Storage) can only be cleared from within the page's own JavaScript environment. The injected scripts are static functions defined within the extension's own codebase, loaded from the extension package. No remote code, no dynamic evaluation, and no user-supplied scripts are ever executed.

Host Permissions: Cookie Nuker does not request any host permissions. All operations are scoped to the active tab via the activeTab permission.

Data Usage

The extension accesses browser APIs solely to perform deletion operations on the current website. Specifically:

  • ✓The active tab's URL is read to display it in the popup interface and to determine which origin's data needs to be cleared
  • ✓Cleanup scripts are injected into the active tab to clear page-level storage
  • ✓Chrome's browsingData API is called to remove cookies and other browser-level storage for the current origin
  • ✓The tab URL may be updated to strip tracking parameters before reloading

All data accessed through these APIs is processed locally and immediately discarded after deletion. No data is logged, stored, transmitted, or retained.

The extension does not access, read, or transfer the contents of cookies, localStorage items, IndexedDB databases, or any other stored data. It only calls the appropriate API methods to delete them.

Data Sharing

Cookie Nuker does not share any data with any party:

  • ✗No third-party advertisers
  • ✗No analytics services
  • ✗No developers or external servers
  • ✗No social media platforms
  • ✗No data brokers
  • ✗No government agencies
  • ✗No other parties of any kind

The extension makes zero network requests. There is no data to share.

Data Retention

Cookie Nuker does not retain any user data. All operations are ephemeral:

  • ✓Tab URLs are held in memory only while the popup is open
  • ✓Storage deletion results are displayed temporarily in the popup and discarded when the popup closes
  • ✓No data is written to disk, localStorage, IndexedDB, or any persistent storage by the extension itself
  • ✓No logs are maintained
  • ✓No cookies are set by the extension

User Control

Users have full control over the extension's behavior:

  • ✓The extension does nothing until the user clicks the NUKE EVERYTHING button
  • ✓Users can select which specific storage types to clear via checkboxes in the popup
  • ✓The auto-reload toggle can be turned off to prevent automatic page refresh
  • ✓Users can disable or uninstall the extension at any time through Chrome's extension management page
  • ✓The extension operates exclusively on the currently active tab and never affects background tabs or other windows

Security

All data deletion operations are performed using Chrome's official, documented extension APIs. The extension:

  • ✓Cannot access data from other extensions
  • ✓Cannot access system-level information
  • ✓Cannot read or modify files on the user's computer
  • ✓Cannot access pages the user has not explicitly targeted by clicking the extension action
  • ✓Does not use any form of remote code execution
  • ✓Does not use eval or dynamic script injection
  • ✓Does not load external resources or make network connections

Children's Privacy

Cookie Nuker is not directed at children under the age of 13. The extension does not collect any personal information from any user, including children.
