Overview

This Privacy Policy describes how the Cookie Nuker Chrome browser extension ("Extension"), developed by CORE10 ("we", "us", "our"), handles information when you install and use it.

Cookie Nuker is a browser utility tool. It performs all operations locally within your browser. It does not operate as a web service, does not communicate with any external servers, and does not collect, transmit, or store any information about you or your browsing activity.

Data Collection

Cookie Nuker does not collect any data. Specifically, the extension does not collect:

  • ✗Personal information — no names, emails, identifiers, or account details
  • ✗Browsing history — no record of websites you visit
  • ✗Usage data or analytics — no tracking of when or how you use the extension
  • ✗Cleared storage contents — the data being cleared is never read or stored by us
  • ✗Device information — no hardware, OS, or browser fingerprinting
  • ✗Crash or error reports — no telemetry is sent anywhere

How the Extension Works

Cookie Nuker operates entirely within your local browser environment. When you click the "Nuke Everything" button, the extension:

  • ✓Reads the URL of your currently active tab to determine which site's storage to clear (this URL is never transmitted anywhere)
  • ✓Calls Chrome's built-in APIs (cookies, browsingData, scripting) to delete storage data locally
  • ✓Injects a cleanup script into the active tab's page context to access page-level storage objects
  • ✓Returns a local results report to the popup UI — this report exists only in memory and is discarded when the popup closes

No information from any of these operations is written to disk, sent to any server, or persisted beyond your active browser session.

Permissions Explained

Cookie Nuker requests the following Chrome permissions. Each is necessary for the extension to function and is used solely for the purpose described:

Permission Why It's Needed
tabsRead the active tab's URL so the extension knows which site's storage to target. Never used to access other tabs.
cookiesRequired to read and delete cookies via Chrome's cookies API for the active site only.
browsingDataAllows clearing of storage buckets, HTTP cache, IndexedDB, and WebSQL through Chrome's official clearing API.
scriptingInjects a cleanup script into the active tab to clear localStorage, sessionStorage, Cache Storage, and Service Workers from within the page context.
activeTabGrants temporary permission to interact with the tab you're currently viewing. Does not grant access to other tabs.
storageReserved for potential future extension settings. Not actively used in v1.0.0.
debuggerReserved for potential advanced debugging features. Not actively used in v1.0.0.
<all_urls>Chrome requires explicit host permissions to clear storage for any given site. This permission covers all sites but the extension only operates on the single active tab you explicitly choose to nuke.

The <all_urls> permission may appear broad, but Cookie Nuker only ever acts on the one tab you have open and choose to nuke. It does not passively monitor, read, or interact with any other tabs or websites.

Third-Party Services

Cookie Nuker does not use any third-party services, analytics platforms, advertising networks, crash reporting tools, or tracking libraries. The extension contains no external scripts or network requests of any kind.

The extension's source code is available for inspection. There are no hidden dependencies, no obfuscated code that calls home, and no bundled trackers.

Local Storage by the Extension Itself

Cookie Nuker may save minimal user preferences (such as the Auto-Reload toggle state) locally using Chrome's built-in chrome.storage API. This data:

  • ✓Is stored only on your device, never on any server
  • ✓Contains only UI preference flags (true/false values), never personal data
  • ✓Can be cleared by removing the extension from Chrome

Children's Privacy

Cookie Nuker is a developer/privacy utility tool not directed at children. We do not knowingly collect information from anyone, including children under the age of 13. Since the extension collects no information from any user whatsoever, this is not a practical concern.

Changes to This Policy

If we make material changes to this Privacy Policy — for example, if a future version of Cookie Nuker introduces new functionality that involves data handling — we will update this page and revise the "Last Updated" date at the top.

We encourage you to review this page periodically. Continued use of the extension after changes constitutes acceptance of the updated policy.

For significant changes, we will also note them in the extension's changelog and on the Chrome Web Store listing.

Open Source & Transparency

Cookie Nuker is released under the MIT License. The full source code is publicly available and can be inspected to verify every claim made in this Privacy Policy. We believe in radical transparency — if you have any doubts about what the extension does, reading the source is the definitive answer.
